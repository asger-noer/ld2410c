# LD2410C

A TinyGo driver for the HLK-LD2410C 24 GHz mmWave presence sensor on the Raspberry Pi Pico (RP2040 and RP2350). On those targets, give `NewDevice` a `*machine.UART` plus the TX, RX, and OUT pins; it configures the peripherals and returns a ready `Device`. Run `Device.Run` in its own goroutine and read decoded measurements — target state, moving and stationary distance, and per-target signal energy — from the `Device.Frames` channel at roughly 10 Hz. Configuration is applied in a single session via `Device.Configure`, which reads the module's current settings first and only writes what differs, so an already-provisioned sensor does not burn flash write cycles on every boot. The read loop also notices a module that has fallen silent in configuration mode and commands it back out, since the separately powered module keeps that state across a host reboot.

The `machine` package is isolated behind the `UART` and `InputPin` interfaces, so the root package compiles and is testable on any host with a standard Go toolchain. All framing, command construction, and response parsing lives in the `codec` subpackage, which imports no hardware and is covered by host tests, so `go test ./...` runs anywhere. The module's OUT pin is read only for diagnostics — the frame stream is the authoritative source of presence, and per-gate sensitivity thresholds are the primary noise-rejection mechanism.
